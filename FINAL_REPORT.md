## 🚀 Быстрый запуск (recap)

### 1. Настройка

```bash
# Распаковать архив
tar -xzf investlab.tar.gz
cd investlab

# Создать .env
cp .env.example .env

# Отредактировать:
# - BOT_TOKEN (от @BotFather)
# - WEBAPP_URL (URL вашего frontend)
# - API_SECRET_KEY (openssl rand -hex 32)
```

### 2. Запуск backend

```bash
docker-compose up -d
docker-compose logs -f bot
```

### 3. Запуск frontend

```bash
cd frontend
npm install
npm run dev
# Или для production:
npm run build
# Загрузить dist/ на Vercel/Netlify
```

### 4. Настройка бота в Telegram

1. Получить токен у [@BotFather](https://t.me/botfather)
2. Создать Mini App: `/newapp`
3. Указать URL вашего frontend
4. Запустить бота: `/start`
