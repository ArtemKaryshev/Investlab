# Contributing to InvestLab

Спасибо за интерес к проекту! Мы рады любому вкладу.

## Как внести вклад

### 1. Fork и клонирование
```bash
git clone https://github.com/your-username/investlab.git
cd investlab
```

### 2. Создание ветки
```bash
git checkout -b feature/your-feature-name
```

### 3. Внесение изменений
- Следуйте стилю кода проекта
- Добавляйте комментарии для сложной логики
- Пишите тесты для новых функций

### 4. Тестирование
```bash
# Backend тесты
cd backend
pytest tests/ -v

# Проверка типов (опционально)
mypy backend/
```

### 5. Commit и Push
```bash
git add .
git commit -m "feat: добавлена новая функция X"
git push origin feature/your-feature-name
```

### 6. Pull Request
Откройте PR с описанием:
- Что изменено
- Зачем это нужно
- Как протестировано

## Стиль кода

### Python
- PEP 8
- Type hints где возможно
- Docstrings для публичных функций
- Async/await для I/O операций

### TypeScript/React
- ESLint конфигурация проекта
- Функциональные компоненты с hooks
- TypeScript strict mode
- Именованные экспорты

## Области для вклада

- 🐛 **Исправление багов**
- ✨ **Новые фичи** (лимитные ордера, стоп-лоссы, индикаторы)
- 📚 **Документация** (переводы, туториалы)
- 🎨 **UI/UX улучшения**
- 🧪 **Тесты** (покрытие кода)
- 🌍 **Интернационализация** (поддержка языков)

## Код ревью

Все PR проходят ревью. Ожидайте:
- Обратную связь в течение 2-3 дней
- Возможные правки перед мержем
- Тестирование на тестовом окружении

## Вопросы?

Создайте Issue с тегом `question` или напишите в Telegram.
